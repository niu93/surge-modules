# Surge 高德地图去广告模块

## 正式版 v0.1.1：由 test3 转发布

按用户要求，将已保存的 **v0.1.1-test3** 发布至正式模块 `Amap.sgmodule`。仅调整模块名称、版本及说明，执行规则与 test3 逐字一致；不包含 test4 的个人页精简规则。

### 正式远程安装与更新地址

https://raw.githubusercontent.com/niu93/surge-modules/main/Amap.sgmodule

- 新安装：Surge 模块管理中从 URL 安装上面地址。
- 已安装正式地址：更新该模块，确认名称为“高德地图去广告”、描述为 v0.1.1。
- 之前用测试地址的用户：该测试订阅不会自动变成正式订阅。请先停用测试模块，再安装或启用正式模块，不要两个同时运行。

需要 Surge iOS **5.14.0+**，开启重写、MITM，使用自己生成并已完全信任的 CA。本模块使用原生 jq，不下载或执行远程 JavaScript。

### 功能与边界（与 test3 一致）

1. 打车领券／活动弹窗：清理专用促销接口中已知的两套 popup_list 展示列表。
2. 目的地旁优惠气泡：过滤5303栏位里包含“当单立减”的促销项，不绑定素材或金额。
3. 营销浮标：过滤已见5601类图标，其他图标保留。
4. 营销皮肤槽：仅在已知 skin.dataList[].protocol.skin_list 结构下删除该独立展示槽。这仍是沿用 test3 的局部试验，不保证此前顶部某个横幅一定使用它。
5. 打车下方页面展示精简：过滤活动专区、售卖券包、推广轮播、会员卡展示、里程签到/秒杀/兑换区的五类已见卡片，并同步删除已完全移除类型的布局引用。未知结构保留，不改账户权益或余额。
6. 保留第一版旧开屏 Map Local。**不含后续实时开屏接口拒绝规则**；此前抓包不走旧接口，故当前开屏广告可能不被处理。

**未实现／不包含：**

- test4 的“我的”页订单到借钱一栏以下精简；个人页不因本正式版新增改动。
- 右上角“企”、首页底栏“探索”和“长按说话”的隐藏。
- 对未定位顶部横幅的成功保证。

不修改订单、收藏、钱包、真实会员等级或券/里程资产；不触发购买、兑换、签到、付款或借款。不阻断协议、安全、证照和算法公示等接口。隐藏展示区会同时隐藏其中的快捷入口，使用权益需另找入口或停用模块。

### MITM 与冲突

仅追加 `m5.amap.com` 和 `m5-zb.amap.com`。HTTPS 解密按主机生效，也会涉及这些主机上的其他请求；不关闭服务端证书验证，不改变 CA。

停用重复高德模块、旧版 JS 和测试模块后单独使用。更新后重启高德检查效果及正常打车行为；遇到空位、卡顿、错误或业务异常时先停用。不要驾驶时操作。抓包结束关闭“捕获流量”，不公开凭证、位置或个人数据。

### 发布验证不等于新增真机验证

已核对正式版与固定 test3 的全部有效配置行逐字一致：五条 jq、Map Local 和 MITM 均相同，未掺入 test4 规则。test3 既有28项结构检查、10组URL检查及两份HAR回归结果保留，本次另做25项空值/缺字段原生 jq 回归。

“正式版”表示转到正式分发路径，**不代表本次新增了真机验证或保证所有版本有效**。当前响应结构、实际命中、页面收起/空占位及业务效果仍以设备为准。
