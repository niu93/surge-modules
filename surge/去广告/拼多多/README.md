# 拼多多去广告模块

精简拼多多部分开屏、首页、底栏、搜索、个人中心、聊天推荐及订单相关推广内容。实际效果受 App 版本、接口和网络环境影响，不能保证所有推广内容均被移除。

## 使用

在 Surge 模块管理中添加本模块，启用重写、脚本及所需 MITM，并按 Surge 提示安装和信任自己的 CA。拼多多只启用一份去广告模块，避免多个模块重复改写。

模块包含域名与 QUIC 阻断、HTTP 200 空 JSON 映射、JSON 响应改写，以及扫码取件页响应脚本。部分规则还会精简订单、个人页面板和搜索入口；可能影响推送、图片、聊天、取件、订单详情或推荐刷新。若出现白屏、缺消息或功能异常，请先停用模块对照。

扫码取件脚本会把页面引用的一份 JavaScript 改为从 kelee.one 加载。该二级脚本内容未审查、未固定，扫码功能及外部依赖不能视为已审计或已验证。不要为此关闭证书校验或扩大 MITM 范围。

本地对 JSON 结构、URL 边界、异常透传及已有响应做过静态测试；这不等于设备导入、请求命中或 UI／业务无损验证。建议首次使用时逐项检查首页、聊天、通知、个人页、订单和扫码取件。
