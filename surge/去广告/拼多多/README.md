用户提供的新抓包确认：两次主页响应均有当前模块Body Rewrite记录，两条底栏数组都只剩首页/聊天/个人中心，但用户确认同次界面仍五项。因此不能再归因为简单的规则未载入或数组未过滤，也不能认定缓存/皮肤就是根因。

## 本次唯一新增处理

在精确接口`api.pinduoduo.com/api/alexa/homepage/hub`中，仅当根对象、result及selected_bottom_skin均为对象时，删除selected_bottom_skin；缺字段或错误类型时透传，jq异常返回原输入。先执行现有底栏数组规则，再做这条字段删除。

该字段在两份最新响应中均有三份皮肤变体、5至6个图标槽位，仍包含与目标入口group相同的11/14键。**键相同和图标存在不能证明它决定Tab个数**，也不证明它会注入入口。

公开[Newflav/Quantumult-X固定参考](https://github.com/Newflav/Quantumult-X/blob/a2a05765382aea1973e4a5ec06ce867e47e6a2c7/rewrite/pdd.snippet)在同一接口删除该字段，是本实验的行为参考，不是当前客户端隐藏“多多视频/双11”的效果证明。本模块使用独立类型保护表达式，不复制参考中的其他拦截或首页精简。

## 使用与验收

1. 更新唯一测试地址，确认v0.2.6-test9，只启用一份拼多多模块。
2. 保持重写与MITM开启、自己的CA已完全信任。建议Surge iOS6，jq最低需iOS5.14+/Mac5.9+；CORE_VERSION>=20仅是通用Body Rewrite门槛。
3. 完全结束拼多多后重新打开，检查首页、聊天、个人中心三个入口及底栏图标，观察视频和双11入口是否隐藏。
4. 若无效，不据此叠加删更多皮肤/实验配置；若图标、布局或加载异常，先停用本模块并反馈，通过同一个测试地址回退test8。
5. 不要求卸载、退出账号、清空App数据或访问任何私人业务URL。网络补丁撤销并不保证清除客户端已有状态。

个人中心/聊天页圈选推荐目前仍未实现，本版不处理也不承诺去除。先前两个失败实验（推荐接口映射与xg阻断）不再加入。
