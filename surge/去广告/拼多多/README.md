# 拼多多去广告与精简模块（v2.0.1）

纯原生 Surge 模块（无远程 JavaScript 脚本），用于精简拼多多首页、底栏、聊天页、个人中心、开屏与全局营销弹窗，同时保留首页的「百亿补贴」与「多多买菜」入口。

## 安装地址

```text
https://raw.githubusercontent.com/niu93/surge-modules/main/surge/%E5%8E%BB%E5%B9%BF%E5%91%8A/%E6%8B%BC%E5%A4%9A%E5%A4%9A/Pinduoduo.sgmodule
```

## 主要内容

- **网络通道回落（`[Rule]`）**：拦截拼多多自带 HTTPDNS（`/d`、`/d5`、`/v3/d`）、QUIC、长连接域名（`meta`、`xg`、`titan*`、`longlink`、`api-ipv6`）及部分统计上报域名。两条 HTTPDNS 规则使用 `REJECT-DROP`，降低快速失败触发的重试；其余拒绝规则仍使用 `REJECT-NO-DROP`。
- **首页精简（`[Body Rewrite]`）**：保留底栏三项（首页、聊天、个人中心）及首页「百亿补贴」「多多买菜」入口；移除首页金刚区、异形横幅、拼小圈入口与顶部非默认推广标签。
- **聊天与个人中心精简（`[Map Local]` / `[Body Rewrite]`）**：清理开屏、悬浮活动页、聊天推荐流、兜底推荐流及个人中心推广图标与横幅。

## 使用说明

1. 在 Surge 模块管理中安装上述地址，确保开启 Rewrite 与 MITM，并信任本机 Surge CA。
2. 同一个 App 请只启用这一份拼多多去广告模块，避免与旧模块规则冲突。
3. 首次切换或更新后，如底栏或首页模块未即时刷新，可在拼多多「设置 → 清除缓存」后完全划掉后台重进。
4. 若遇到聊天消息延迟、图片或活动页异常，请先停用本模块对照排查。

## 说明

本模块基于已抓包的首页 JSON 结构独立编写并通过离线回放与语法验证；实机刷新表现、长连接回落稳定性及各项业务功能（下单、聊天、推送、个人中心等）请以设备实测为准。
